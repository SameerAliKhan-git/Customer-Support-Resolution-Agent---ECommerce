# ElectroVault Global - Return Processing Policy
Document ID: return_policy_v1
Version: 1.0
Effective Date: 2026-01-01

## Section 1: Standard Return Window
1. Customers may request a return within 30 calendar days from the confirmed delivery date.
2. Orders older than 30 days are past the standard return eligibility window and cannot be returned for a standard refund unless authorized by a senior supervisor exception.

## Section 2: Return Lifecycle and Status Tracking
Every return follows an auditable lifecycle:
- REQUESTED: Return label issued to customer; package awaiting handover to carrier.
- IN_TRANSIT: Carrier has scanned and picked up package; tracking number is active.
- RECEIVED: Package has arrived at warehouse intake dock.
- INSPECTION_PASSED: Warehouse staff verified contents, serial number, and condition.
- INSPECTION_FAILED: Item returned in unacceptable condition or incorrect item returned.
- REJECTED: Return denied due to policy violation.

## Section 3: Non-Returnable and Excluded Categories
1. Opened consumable goods (batteries, thermal paste, cleaning kits) cannot be returned once unsealed.
2. Digital software codes, licenses, or downloaded content are strictly non-returnable.
3. Custom-configured computers or engraving-modified hardware are non-returnable unless defective on arrival.
